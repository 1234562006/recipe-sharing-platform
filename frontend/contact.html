Frequently Asked Questions

How do I publish a recipe?

Simply create an account or sign in, then click the "+ Add Recipe" button in the navigation bar to fill in ingredients, steps, and photos.

Can another user edit my recipe?

No. The backend strictly verifies that only the original author possesses ownership authorization to edit or delete a recipe.

Where is the recipe data stored?

All user profiles, recipes, and favorites are stored in a cloud-hosted MongoDB Atlas database via Mongoose models.

How do I check system health?

Visit the /api/health endpoint to view uptime and database status.
