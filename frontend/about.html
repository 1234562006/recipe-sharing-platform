About RecipeNest

RecipeNest is a production-grade full-stack recipe sharing web application engineered to demonstrate modern full-stack web development practices, RESTful architectural design, and secure MongoDB persistence.

System Architecture & Technology Stack

Frontend Layer

Clean HTML5 semantic elements, custom modern CSS3 design tokens with responsive Flexbox/Grid, and modular Vanilla JavaScript.

Backend REST API

Node.js and Express.js providing JSON RESTful endpoints, rate limiting, and centralized error handling middleware.

Database & ODM

MongoDB Atlas cloud cluster with Mongoose schemas, text search indices, compound unique favorite relationships, and virtual getters.

Authentication & Security

bcrypt salted password hashing, JSON Web Tokens (JWT) verification, recipe ownership authorization, and strict input validation.

Key Platform Capabilities

  • ✓ Full Recipe CRUD: Authenticated users can create, read, update, and safely delete their own recipes.
  • ✓ Dynamic Multi-filter Search: Live full-text search across titles and ingredients combined with category, difficulty, and max cook time filters.
  • ✓ Favorites Bookmark Relationship: Database-backed user favorites preventing duplicates via compound unique indexing.
  • ✓ Strict Ownership Protection: Prevents unauthorized users from modifying or deleting dishes created by other chefs.
  • ✓ Graceful Fallbacks: Broken or unavailable image URLs automatically fall back to custom inline SVG graphics.
